# CineScope

A responsive movie discovery web application built as part of a Frontend Engineering Internship assignment.

The project is being developed in two phases:
- Part 1 → Vanilla HTML, CSS, and JavaScript
- Part 2 → React + Vite implementation

---

## Features Planned

- Trending movies banner
- Popular movies grid
- Genre-based filtering
- Live movie search
- Movie detail modal/page
- Dark/light mode
- Favorites system (React phase)

---

## Tech Stack

### Part 1
- HTML5
- CSS3
- Vanilla JavaScript
- TMDB API

### Part 2
- React
- Vite
- React Router
- CSS Modules
- TMDB API
